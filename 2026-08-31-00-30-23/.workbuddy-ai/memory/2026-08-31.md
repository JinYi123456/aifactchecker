## Hackathon: Gonka AI Fact Checker (Streamlit single-file app)
- Built `app.py` (471 lines) + `requirements.txt` for a hackathon fact-checker.
- Uses OpenAI SDK against Gonka Router base_url `https://api.gonkarouter.io/v1`,
  api key from env `GONKA_API_KEY` or sidebar input.
- Concurrent (ThreadPoolExecutor, max_workers=2) calls: `deepseek-ai/DeepSeek-V4-Flash-0731`
  (logic-hole extraction) + `MiniMaxAI/MiniMax-M2.7` (long-text/fact comparison).
- Arbiter (reuses DeepSeek-V4-Flash) fuses both -> Truth Score 0-100 + Verdict
  (REAL/MOSTLY_REAL/PARTLY_DUBIOUS/HIGHLY_DUBIOUS/FAKE/UNKNOWN) + Reasoning Trace.
- Transparency dashboard shows both analyses + each model's Gonka Request ID = response.id.
- Robust JSON extraction (extract_json), per-model try/except so one failure doesn't break all.
- Syntax verified via py_compile (streamlit/openai not installed in managed env).
- Run: `pip install -r requirements.txt` then `streamlit run app.py`.
